## 📌 Project Overview

Moveryy Backend is a production-ready REST API built using Node.js and Express.  
It provides secure authentication, organization management, and inventory APIs with JWT-based authorization.

This backend is designed to work with Android, Web, or any frontend client.

---

## 🛠 Tech Stack

- 🟢 Node.js
- ⚡ Express.js
- 🔐 JWT Authentication
- 🔑 Bcrypt Password Hashing
- 🗄 PostgreSQL / MySQL
- 🌍 CORS
- 📦 Drizzle ORM / Sequelize / Prisma (Choose yours)
